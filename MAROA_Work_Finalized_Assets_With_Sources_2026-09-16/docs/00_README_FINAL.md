# MAROA Work Finalized Assets (interim-final)

Paket ini menambahkan **aset cover website-ready** berbasis lampiran yang diberikan user, plus **register sumber eksternal** yang dapat dipakai developer/editor saat melengkapi galeri dan kredit sumber.

## Isi utama
- `covers_webp/` : cover kandidat ukuran 1600x900 WebP siap web
- `covers_jpg/` : cover kandidat ukuran 1600x900 JPG siap review
- `video_stills/` : cuplikan frame video untuk opsi galeri/cover
- `docs/EXTERNAL_SOURCES_REGISTER.csv` : daftar sumber eksternal/official untuk kredit dan validasi
- `docs/WEBSITE_READY_MATRIX.csv` : status kesiapan tiap cover
- `docs/GENERATED_COVERS_MANIFEST.json` : manifest asal-usul file hasil olahan

## Prinsip editorial
1. Cover hasil olahan di sini aman dipakai untuk proyek **berbasis desain**.
2. Untuk proyek **berbasis event nyata**, cover desain boleh dipakai hanya jika peran MAROA memang pada desain/backdrop/visual promosi.
3. Galeri event nyata **tetap perlu foto dokumentasi asli**. Jika memakai foto dari sumber eksternal, wajib simpan URL sumber dan kredit.
4. Jangan menyajikan materi generatif seolah-olah foto kegiatan nyata.
